# Brand Logos Directory

This folder contains all brand logos for the Trusted Brands section.

## How to Add New Brand Logos:

1. Upload your brand logo image (PNG, JPG, or WEBP format recommended)
2. The image will be imported using the `figma:asset` scheme
3. Add the import to `/config/brands.ts`
4. Add the brand entry to the brands array

## Best Practices:

- Use transparent PNG logos when possible
- Recommended size: 200-400px width
- Keep file sizes optimized (under 100KB per logo)
- Use consistent logo formats across all brands
